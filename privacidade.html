Já Disseram Isso

Política de privacidade

Atualizada em 28 de outubro de 2026.

O aplicativo ja-disseram-isso-analista é uma ferramenta interna do canal Já Disseram Isso. Ele existe para que o próprio dono do canal acompanhe o desempenho dos seus vídeos. Não é oferecido a outras pessoas.

Quais dados o aplicativo acessa

  • Somente dados do canal Já Disseram Isso, autorizados pelo próprio dono do canal.
  • Permissões apenas de leitura: estatísticas do YouTube Analytics (visualizações, tempo assistido, retenção, origem do tráfego, inscritos) e informações públicas dos vídeos do canal (título, data, duração).
  • O aplicativo não publica, não altera e não apaga nada no YouTube, e não acessa dados de espectadores individuais.

Como os dados são usados e guardados

  • As métricas agregadas são gravadas uma vez por dia num repositório privado do dono do canal, para análise de desempenho e planejamento de novos vídeos.
  • Os dados não são vendidos, compartilhados nem usados para publicidade.
  • O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, o aplicativo deixa de coletar dados.

Contato

Pelo e-mail de suporte informado na tela de autorização do Google.
